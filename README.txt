文件关联管家 v0.2.1
===================

一个 Windows 10/11 便携式文件关联查看与维护工具。无联网、无安装、
不改系统级设置。

能做什么
--------
1. 扫描结果：查看本机所有文件扩展名的打开方式，自动找出"失效"关联
   （程序已卸载、路径不存在）和"无法判断"的关联（UWP 应用等）。
2. 清理残留：勾选失效条目一键清理（右键"打开方式"里的幽灵项）。
   每条清理前自动备份，可随时恢复。
3. 备份与恢复：查看全部操作历史，一键恢复任何一次清理。
4. 我的关联：为便携软件注册文件关联（格式可搜索选择），
   撤销时自动恢复注册前的状态。

安全说明
--------
- 只操作当前用户（HKCU）的关联设置，不触碰系统级（HKLM）数据；
- 所有删除操作先备份后执行，可完全恢复；
- 不绕过 Windows 默认应用保护：受保护格式（如 PDF）的默认程序
  需要在系统设置中手动更改，本工具会如实告知，不做虚假承诺。

使用方法
--------
解压后双击 FileAssocManager.exe 即可，无需安装。
建议放在固定位置（如 D:\tools\），不要放在桌面临时解压。

杀毒软件提示（重要）
--------------------
本工具使用 PyInstaller 打包，部分杀毒软件会对其误报（常见的启发式
误判，与软件内容无关）。处理办法：

Windows Defender 添加信任：
  1. 打开「Windows 安全中心」→「病毒和威胁防护」；
  2. 点「管理设置」→ 找到「排除项」→「添加或删除排除项」；
  3. 添加排除项 → 选择「文件夹」→ 选中解压后的 FileAssocManager 文件夹。

其他杀毒软件：在其信任区/白名单中添加本文件夹即可。
若 Defender 已拦截：通知中心点开提示 → 选择「允许」。

校验完整性
----------
发布包附带 SHA-256 校验和（.sha256 文件）。PowerShell 中执行：

  Get-FileHash .\FileAssocManager-v0.2.1-win-x64.zip -Algorithm SHA256

与 .sha256 文件中的值一致即说明下载完整未被篡改。
