文件关联管家 v0.3.2
===================

给被"右键 → 打开方式里一堆幽灵程序"困扰的 Windows 用户。
只诊断和清理失效条目，不替换你的默认应用，不改系统级设置，
不需要管理员权限。

能做什么
--------
1. 扫描结果：查看本机扩展名的打开方式，自动标出"失效"和"无法判断"
   的关联，并说明原因（程序已卸载、ProgID 缺失、UWP 应用等）。
2. 清理残留：勾选"失效"条目一键清理（右键"打开方式"里的幽灵项）。
   每条清理前自动备份，可随时恢复。
3. 备份与恢复：查看操作历史，按条恢复任何一次清理。
4. 我的关联：为便携软件注册文件关联（格式可搜索选择），
   撤销时自动恢复注册前的状态。

能清什么，不能清什么
--------------------
- 只能清理判定为"失效"的条目；
- "无法判断"的条目（UWP 应用、系统组件托管、ProgID 没有打开命令）
  不能清理，删了系统也会重建；
- 有效的打开方式条目不能删——本工具不是"打开方式列表管理器"。

清理边界
--------
- 只删单个注册表值，不删除键，也不碰 ProgID 键树；
- 只写当前用户（HKCU）的设置，系统级（HKLM）全程只读；
- 删除打开方式条目时，会同步修正 MRUList，避免留下悬挂引用。

数据与备份
----------
- 操作日志与快照保存在 %APPDATA%\FileAssocManager\；
- 只保留最近 500 次操作，更早的记录会连同对应的 .reg 快照一起删除；
- 便携模式：在 FileAssocManager.exe 同目录新建一个空文件夹 data\，
  之后所有记录都写在这个文件夹里，换机器时整个文件夹拷走即可；
  删除 data\ 则恢复使用 %APPDATA%。

安全说明
--------
- 只操作当前用户（HKCU）的关联设置，不触碰系统级（HKLM）数据；
- 不联网，不收集文件名、路径或注册表内容；
- 所有删除操作先备份后执行，可按条恢复；
- 不绕过 Windows 默认应用保护：受保护格式（如 PDF）的默认程序
  需要在系统设置中手动更改，本工具会如实告知，不做虚假承诺。

使用方法
--------
解压后双击 FileAssocManager.exe 即可，无需安装。
建议放在固定位置（如 D:\tools\），不要放在桌面临时解压——
程序会记住这个位置，移动后建议重新解压到新目录。

杀毒软件提示（重要）
--------------------
本工具使用 PyInstaller 打包，部分杀毒软件会对其误报（常见的启发式
误判，与软件内容无关）。处理办法：

Windows Defender 添加信任：
  1. 打开「Windows 安全中心」→「病毒和威胁防护」；
  2. 点「管理设置」→ 找到「排除项」→「添加或删除排除项」；
  3. 添加排除项 → 选择「文件夹」→ 选中解压后的 FileAssocManager 文件夹。

其他杀毒软件：在其信任区/白名单中添加本文件夹即可。
若 Defender 已拦截：通知中心点开提示 → 选择「允许」。

校验完整性
----------
发布包附带 SHA-256 校验和（.sha256 文件）。PowerShell 中执行：

  Get-FileHash .\FileAssocManager-v0.3.2-win-x64.zip -Algorithm SHA256

与 .sha256 文件中的值一致即说明下载完整未被篡改。
