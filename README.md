# 文件关联管家

面向 Windows 10/11 的便携式文件关联查看与维护工具。

## 当前阶段

项目处于设计阶段。本阶段只建立规范和设计边界，不执行真实注册表写入或删除。

## 目标

- 查看当前用户的扩展名、ProgID 和打开命令；
- 识别明确失效、有效和无法判断的关联；
- 在用户确认后选择性清理打开方式残留；
- 修改前自动备份，并支持恢复；
- 管理由本工具创建的 ProgID。

## 非目标

- 绕过 Windows 默认应用保护；
- 自动修改系统级 `HKLM` 关联；
- 在线规则空间、云同步、目录加密等附加功能；
- 保证 PDF 等受保护格式可以被静默设为默认程序。

详细设计见 [`docs/design.md`](docs/design.md)。
